# 教師教學小工具 🧰

課堂上常用的小工具集合，單一 HTML 檔案、免安裝、離線可用。
所有資料（班級名單、計分板）只存在你自己的瀏覽器裡，不會上傳到任何地方。

## 功能

| 工具 | 說明 |
|---|---|
| 👥 名單設定 | 座號模式或姓名模式，可排除缺席號碼；抽籤／分組／轉盤／隨機順序共用 |
| ⏳ 倒數計時 | 快捷 1/3/5/10 分或自訂；剩 30 秒變黃、10 秒閃紅，時間到有提示音 |
| ⏱️ 碼表 | 計時、分段紀錄 |
| 🎯 依序抽籤 | 不重複抽人，記錄已抽出順序與剩餘名單 |
| 🧩 隨機分組 | 指定組數或每組人數，自動平均分配 |
| 🎡 幸運轉盤 | 動畫轉盤，可設定抽中後移除 |
| 🏆 計分板 | 小組加減分，自動標示領先組別，關閉後分數仍保留 |
| 🔀 隨機順序 | 打亂全班名單（例如上台報告順序） |
| 🔊 音量偵測 | 用麥克風偵測教室音量，超過警戒線提醒安靜 |

## 使用方式

直接開啟網頁即可，不需要安裝任何東西。

如果要在自己電腦上用，也可以把 `index.html` 下載下來用瀏覽器打開。

## 注意事項

- 「音量偵測」需要允許瀏覽器使用麥克風，且必須透過 `https://` 開啟（GitHub Pages 本身就是 https，沒問題）。
- 名單與計分板存在瀏覽器的 localStorage，換電腦或清除瀏覽資料後會消失。
